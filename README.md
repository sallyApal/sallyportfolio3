# Sally Asfour — Portfolio

A responsive personal portfolio website for Sally Asfour, an aspiring Full-Stack Developer transitioning from administration and operations into technology.

## Files
- `index.html` — portfolio structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation and footer year

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new repository (for example, `sally-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js`.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select your main branch and the `/root` folder.
6. Save and open the generated Pages URL.
